A collection of my Python programming exercises, data structures and algorithms (DSA) practice, and problem-solving activities.

I'm a BS Data Science student building my programming fundamentals through regular practice. This repository documents my learning progress, including solutions, experiments, and exercises that I'm continuing to improve.

## About This Repository

The repository includes both LeetCode-style problem solving and general Python practice. Not every script is a submission to LeetCode; some files contain foundational exercises and small learning projects.

My goals are to:

- Strengthen Python fundamentals and logical thinking.
- Understand algorithms by implementing them from scratch.
- Practice searching, sorting, and analyzing time complexity.
- Improve code readability and debugging skills.
- Track my progress consistently.

## Getting Started

**Requirements:** Python 3. No third-party packages are required for the example scripts listed above.

Clone the repository:

```bash
git clone https://github.com/Usmanshakir7/LEETCODE-_PRACTICE_-PYTHON-.git
cd LEETCODE-_PRACTICE_-PYTHON-
```

Run a practice file, for example:

```bash
python leetcode_practice_day_21.py
```

Most scripts use example values written directly in the code. Some interactive programs ask for input in the terminal. Individual files may contain multiple exercises and are not presented as a single test suite.
